# LOOKOPTICS AR v2.2.0

v2.1 리뷰의 보완 항목을 반영한 최종본. 구조(세션 토큰·추론 watchdog·sRGB 색 파이프라인·468점 오클루더·RGBE 환경맵·재질 JSON)는 v2.1 그대로 유지.

## 파일 구성 (변경됨)
```
index.html              진입 (캐시 우회, 수정 불필요)
app.html                앱 본체 (0.76MB, 이전 2.4MB)
assets/LK-S001/         SKU별 자산
  model.glb  thumb.jpg  ao_front.png  ao_temple_l.png  ao_temple_r.png  front_tex.jpg  pad_l.png  pad_r.png
```
GitHub 업로드 시 `assets` 폴더째 올린다(upload 화면에 폴더 드래그 가능). 새 SKU는 `assets/<SKU>/` 폴더와 `CATALOG` 항목 하나를 추가하면 된다.

## 실기기 확인 항목
1. iPhone Safari·중급 Android: 반사 표시, 15/30/45° 반대쪽 템플 방향(고개를 왼쪽으로 돌리면 화면상 오른쪽 템플이 사라져야 함), 템플 페이드 경계
2. 5분 연속 FPS·발열. 30fps 미달 시 `settings.perspective`·해상도 상한(1.25) 조정
3. 시작 직후 2~3초 정면 유지 시 상태 표시가 "크기 보정 적용"으로 바뀌는지
4. 보정 끄기/켜기 비교: 암부 계조, 피부 경계
