## v2.3 변경 — 자세 추정 교체 (좌우 회전 시 뜨는 현상)
- 얼굴 자세: 랜드마크 z 추정값 + 뺨/이마 축 → **MediaPipe 정준 얼굴 모델(468점, mm) + PnP**(가우스-뉴턴, 코시 가중). 2D 랜드마크만 사용하므로 깊이 추정 오차가 자세에 들어가지 않음
- 카메라: 정사영 + 투영행렬 보정(약한 원근) → **실제 원근 카메라**. 화각은 장변 기준 `settings.fov`(기본 70°, 설정 패널 55~85°). SKU `fit.fovDeg`로 기본값 지정 가능
- 월드 단위 mm. 안경은 `scale=1000`, 착용 오프셋 `fit.up/fwd`·`heightAdjust/depthAdjust`는 실측 mm
- 얼굴 오클루더: 화면 위치는 실제 랜드마크, 깊이는 자세 적용 정준 모델 → 영상과 정합 유지하면서 안경과 같은 좌표계
- 홍채 자동 보정·PD 보정: PnP 거리 기준 mm 환산으로 계산 (정준 모델 스케일 보정)
- 제거: `updateFitProjection`, `settings.perspective`, 약한 원근 슬라이더
- 실기기 확인 항목: 기종별 화각(슬라이더로 맞춘 뒤 `fit.fovDeg`에 기록), 반대쪽 템플 방향, 45° 이상에서 랜드마크 자체 오차
